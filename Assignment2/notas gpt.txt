------------- Stage F — Hellinger feature map -------------

O problema está na explicação da experiência.

No teu texto afirmas:
The square root alone (0.600 tiling) is much worse than the full map (0.783), so the normalization after the root matters.

Esta conclusão não está correta.

O motivo é que a função sqrt_only faz apenas:
np.sqrt(x)



Enquanto a função Hellinger faz:
np.sqrt(l1norm(x))



Portanto, estás a comparar:
- Square root sobre histogramas não normalizados.
- L1 normalization antes de aplicar square root.
Não estás a isolar o efeito da L2 normalization depois da raiz.

Aliás, para um histograma não negativo L1-normalizado:
\[
\left\|\sqrt{\mathbf h}\right\|_2^2
=\sum_i h_i=1
\]

Logo, a L2 normalization posterior é matematicamente redundante, salvo diferenças numéricas.

Como corrigir:

Altera a explicação para dizer que a melhoria resulta sobretudo da normalização L1 antes da aplicação da raiz quadrada.

Se quiseres demonstrar experimentalmente que a L2 posterior é redundante, compara:
def hellinger_without_final_l2(x):    return np.sqrt(l1norm(x))def hellinger(x):    return l2norm(np.sqrt(l1norm(x)))

Os resultados devem ser praticamente iguais.

Esta é uma correção importante, porque o enunciado pergunta especificamente sobre a ordem das normalizações.
